# Pi_CN 汉化维护

本目录保存 Pi_CN 的构建数据快照和汉化维护说明。`model-data/` 是本 Fork 在上游 v1.2.0 源码上生成并验证的构建快照，不代表上游发布时使用的数据。来源、生成时间和版本记录在 `model-data/snapshot.json`，文件哈希与结构校验位于 `model-data/data/.manifest.json`。

## 更新流程

1. 对比目标上游版本，先恢复核心错误、事件字段、工具结果和协议数据的上游原文。
2. 更新英文文案表，以对应上游界面原文为准；同步更新模型数据快照和 `snapshot.json`。
3. 补齐中文文案。英文与中文必须具有相同键和参数，界面变量应作为整句参数处理。
4. 运行 `npm run prepare:zh`、`npm run check` 和 `npm run build:zh`。完整隔离测试前先用 `npm run build:daemon --workspace packages/env` 构建上游新增的 Rust 测试守护进程，再运行 `./test.sh`；macOS 可用 `TMPDIR=/tmp ./test.sh` 避免 Unix socket 路径过长。
5. 在 40、80、120 列终端中检查中英文布局，并人工检查真实中文输入法候选框位置。

## 边界

文案层只负责程序管理的 CLI/TUI 显示。模型输出、用户内容、外部扩展文案、系统提示词、协议值、凭据输出、HTML 导出和上游长篇文档保持原样。语言仅保存到全局设置；项目设置不得覆盖它。

更新快照时应使用与当前源码对应的上游生成脚本，保留生成来源和时间，并通过现有模型数据校验。构建过程不得在快照异常时静默下载其他数据。

合并冲突后应逐项对照上游差异，特别检查终端异常退出、程序状态通知、工具记录耗时和输出内边距；保留译文时不能覆盖同一区域的上游行为修复。
