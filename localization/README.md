# Pi_CN 汉化维护

本目录保存 Pi_CN 的构建数据快照和汉化维护说明。`model-data/` 是本 Fork 在上游 v0.87.1 源码上生成并验证的构建快照，不代表上游发布时使用的数据。来源、生成时间和版本记录在 `model-data/snapshot.json`，文件哈希与结构校验位于 `model-data/data/.manifest.json`。

## 更新流程

1. 对比目标上游版本，先恢复核心错误、事件字段、工具结果和协议数据的上游原文。
2. 更新英文文案表，以对应上游界面原文为准；同步更新模型数据快照和 `snapshot.json`。
3. 补齐中文文案。英文与中文必须具有相同键和参数，界面变量应作为整句参数处理。
4. 运行 `npm run prepare:zh`、`npm run check`、`npm run build:zh` 和 `./test.sh`，分别验证快照、静态检查、离线构建和隔离测试。
5. 在 40、80、120 列终端中检查中英文布局，并人工检查真实中文输入法候选框位置。

## 边界

文案层只负责程序管理的 CLI/TUI 显示。模型输出、用户内容、外部扩展文案、系统提示词、协议值、凭据输出、HTML 导出和上游长篇文档保持原样。语言仅保存到全局设置；项目设置不得覆盖它。

更新快照时应使用与当前源码对应的上游生成脚本，保留生成来源和时间，并通过现有模型数据校验。构建过程不得在快照异常时静默下载其他数据。
